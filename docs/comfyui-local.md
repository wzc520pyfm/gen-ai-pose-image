# ComfyUI 本地生成

在原工作室的「生图设置」中切换「ComfyUI 本地」。在线图库、内置模特、自己的参考素材、历史与下载沿用原有功能；原云端配置和默认生成方式不变。

## 启动

工作室的服务端与 ComfyUI 必须在**同一台电脑**。公开网站服务器上的 `127.0.0.1` 指服务器，不是访问者的电脑；此接入不适用于 GitHub Pages。

先按正常方式启动 ComfyUI，再启动工作室。例如 Windows PowerShell：

```powershell
$env:LANPOSE_COMFYUI = '1'
npm run dev -- --hostname 127.0.0.1
```

Linux/macOS：

```sh
LANPOSE_COMFYUI=1 npm run dev -- --hostname 127.0.0.1
```

打开终端显示的本机地址，进入设置，选择本地生成并点击「测试本机连接」。如 ComfyUI 使用其他端口，可在启动工作室前设置 `LANPOSE_COMFYUI_URL=http://127.0.0.1:8189`。仅接受回环地址，不接受远程服务器、路径、凭据或查询参数。未显式设置 `LANPOSE_COMFYUI=1` 时禁用本地调用。Harness 内嵌工作室使用相同环境变量和适配器，需要本机运行 Harness。

## 使用与工作流

- 只选服装：保留原姿势换装；只选姿势：保持原服装换姿势；两者都选：换装并换姿势。至少选择一个。
- 未选服装时，仍可关闭原来的「保持服装」，按补充描述允许更换衣服。
- 多张模特照片仍表示同一个人。双人姿势沿用上游含义：主角保持参考身份，第二人按姿势生成，不分别指定两套身份。
- 逐张模式串行生成；拼图最多四格，逐格生成后由程序按选择顺序留白排版。单格失败时保留已完成结果，再点生成会在十分钟内复用相同请求的成功格；修改参考或参数会重新生成。缓存仅驻留内存，最多保留四个拼图任务；重启服务会清除。
- 「停止」停止后续提交和等待，并尝试移除本次尚未执行的任务。已开始的 ComfyUI 任务仍会完成，避免全局中断其他任务。
- 人物照等比例留白到所选比例。拼图外框也遵循该比例；不会拉伸图片。

统一画布位于 [`local-tryon.canvas.json`](../shared/workflows/local-tryon.canvas.json)，运行文件位于 [`local-tryon.api.json`](../shared/workflows/local-tryon.api.json)。将画布拖入 ComfyUI，顶部「启用换装」「启用姿势」控制分支。网页自动设置开关，并在提交前裁剪关闭分支，因此只换装不需要安装 MOSS 分支依赖。

画布按输入、Qwen 共享模型、换装、MOSS 模型、姿势控制、分支选择、最终合成和输出分组。模型参数、采样步数等保留在工作流文件中。修改画布后导出 API 格式，将导出对象替换运行文件的 `graph`，保留 `mapping`；改变接口节点时同步调整 `mapping`。每次任务重新读取，无需重启工作室；已提交任务不受影响。执行 `node --test shared/comfyui.test.mjs` 检查连接与映射一致性。

网页会覆盖人物/服装/姿势图片、开关、任务提示词、输出比例、种子和输出前缀。其他采样和模型参数来自运行文件。默认种子为 42，方便对比；本轮没有添加独立的种子界面或通用工作流导入器。

## 依赖与限制

需安装对应 ComfyUI 节点和模型；网页不会下载模型或节点。连接测试检查服务是否可达，生成前检查所用分支的节点和模型选项，任务提交时由 ComfyUI 完整校验。

Qwen 分支使用 Qwen-Image 2.1 Turbo INT8、Qwen3-VL 8B W4A8、对应 VAE、QwenImage21Cache，以及 8 步 Euler sigma 序列。姿势分支另需 MOSS Image SFT INT8、Color/Depth 控制适配器、对应文本编码器与 VAE，以及 Depth Anything V2 Small 预处理器和权重。准确文件名及节点类别见运行文件；只换装不会要求 MOSS 依赖。

内置工作流仅调用本机节点，不发送云端密钥。输入图会写入 ComfyUI `input`，结果写入 `output/tryon`，成功结果还会保存到原有浏览器历史。工作室不记录输入照片或密钥到服务日志。修改成含云端节点的自定义流程后，数据流和费用由这些节点决定，请自行核对。

Qwen 2.1 的模型许可仅供研究或评估，商业使用需要另获授权；素材和其他模型也应分别遵守各自许可，不能由本项目 MIT 许可推导出模型或素材的商用授权。

本地模型会改变脸部细节，双人姿势、遮挡、手部和衣服保持可能不稳定。接口成功返回图片只说明流程完成，不代表人物或姿势完全准确。

## 接口兼容

现有 `/api/generate` 和 `/api/prompt` 请求可增加 `engine: "comfyui"`，省略时仍走原云端路径；`provider` 继续表示原云端配置，避免影响文字扩写等功能。返回值继续使用 `results`，没有另建结果格式。本地拼图可携带不超过 64 字符的 `localRunId`，失败后使用相同标识、参考和参数重试；成功后缓存清除。`GET /api/comfyui` 提供本机连接测试。

## 验证记录（2026-10-31）

Windows、RTX 5070 12 GB，使用两张本地测试照片和上游内置模特。原计划的第三张本地照片已不存在，因此使用内置模特覆盖组合模式；没有将私人测试照片或输出上传到仓库。

| 场景 | 执行结果 | 本机耗时 |
| --- | --- | --- |
| 只换装 | 返回图片 | 约 14 秒 |
| 单人全身姿势 | 返回图片，身份和原服装保持因参考而异 | 约 51 秒 |
| 内置模特＋服装＋姿势 | 返回图片 | 约 45 秒 |
| 半身比心姿势 | 返回图片，原衣服主体和手势有保留 | 约 44 秒 |
| 双人姿势 | 返回两个人，但第二人可能接近主角长相 | 约 40 秒 |
| 多张身份参考 | 返回图片，可能偏向原构图而忽略目标姿势 | 约 55 秒 |
| 两格拼图 | 返回一张拼图，格数、顺序、比例正确 | 约 70 秒 |
| 四格拼图 | 返回一张拼图，格数、顺序、比例正确；各格身份和服装不完全一致 | 约 166 秒 |

以上表示执行链路已验证，不能作为生成质量保证；单人全身和多参考仍需继续调试人物一致性。另测了同一照片及其面部裁剪作为多参考，构图偏向问题仍存在。

`npm test` 共 47 项通过，`npm run typecheck`、`npm run lint`、`npm run build` 通过。工作室真实网页完成只换装，刷新后历史保留并可「再用」；生产模式 HTTP 接口也实际返回图片。同源请求通过，外站来源被拒绝。内置浏览器未捕获到下载落盘事件，仅核对了有效 PNG 下载链接及文件名；没有进行付费云端真实调用。
